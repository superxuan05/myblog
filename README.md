## 🌟 关于博客

这是一个基于现代前端技术构建的个人博客网站，用于分享技术文章、生活感悟和个人思考。博客采用响应式设计，在各种设备上都能提供良好的浏览体验。

---

## 🚀 功能特点

- ✅ 响应式设计，适配桌面端和移动端
- ✅ 文章分类和标签系统
- ✅ 文章搜索功能
- ✅ 代码高亮显示
- ✅ 评论系统
- ✅ 深色/浅色模式切换
- ✅ 加载动画和过渡效果
- ✅ 性能优化，快速加载

## 🔧 如何运行

1. 克隆仓库：
   ```bash
   git clone https://github.com/superxuan05/myblog.git
   cd myblog
   ```

2. 安装依赖：
   ```bash
   npm install
   ```

3. 启动开发服务器：
   ```bash
   npm run dev
   ```

4. 构建生产版本：
   ```bash
   npm run build
   ```
